«Página web para PDF» foi instalada! 🎉 Veja como começar.

Abra o menu Extensões (1) no canto superior direito do Chrome. Depois, clique no alfinete (2) ao lado de «Página web para PDF» para fixar a extensão na barra de ferramentas.

Tudo pronto! Clique no PDF (3) na barra de ferramentas sempre que quiser guardar uma página web.
